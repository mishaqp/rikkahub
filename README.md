# RikkaHub Agent

**Личный форк RikkaHub для Android с расширенными агентскими возможностями.**

Основан на оригинальном [RikkaHub](https://github.com/rikkahub/rikkahub) и дополнен функциями из [ExTV/rikkahub-agent](https://github.com/ExTV/rikkahub-agent).

[Скачать APK](https://github.com/mishaqp/rikkahub/releases/latest) · [Releases](https://github.com/mishaqp/rikkahub/releases) · [Upstream](https://github.com/rikkahub/rikkahub)

</div>

---

## Основное

- 🤖 расширенные функции Android-агента
- 🧠 локальные LLM на устройстве
- 🛠️ Workspace, инструменты и автоматизация
- ⌨️ поддержка Agent Keyboard

## Установка

Скачайте последний **release APK** из раздела [Releases](https://github.com/mishaqp/rikkahub/releases/latest) и установите его на Android.
